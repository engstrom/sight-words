# Sight Words

A kid's sight-word reading practice app: one `index.html`, served by GitHub Pages at https://engstrom.github.io/sight-words/.

Open it in Safari on the iPad and allow the microphone. Progress lives in the browser's `localStorage` under `sightwords.v1`; Grown-ups › Backup moves it between devices, or between Safari and the Home Screen app, which keep separate storage.
